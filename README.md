# Blicket Task PC game

A static 3D browser game hosted on GitHub Pages. Put each object on the detector, watch whether it activates, then make your choices.

Play at [georgefejer91.github.io/VR-Blicket-Task-Web](https://georgefejer91.github.io/VR-Blicket-Task-Web/).

The game is built with HTML, CSS, JavaScript, and a locally bundled copy of Three.js. Session data stays in the browser until you choose to download JSON. No backend or account is required.

This public repository contains only website files. The main project and research archive are kept separately.
