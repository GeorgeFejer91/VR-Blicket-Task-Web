# Blicket Task PC game

Play the [3D browser game](https://georgefejer91.github.io/VR-Blicket-Task-Web/). Choose English or German, then test three different sets of gray objects on the detector. Each set has six tests: three singles and three pairs. The sequence is disjunctive, disjunctive, then conjunctive; the game leaves that rule for players to infer. Judge all three objects after each set. The complete session JSON downloads automatically after the ninth answer; no session data is uploaded.

The machine's dark body and red platform follow [original university video references](For-AI/machine-references.md). Its widened platform holds two objects side by side, then sinks into a well while a neutral cyan ray scans them. The BLICKET sign and side lamps light up with the result. Bucket and object handling have sound effects, with a tune for activation. The [previous narration assets and voice credit](audio/README.md) remain in the repository but are silent in this sequence because their old prompts describe one-object tests. Sound on/off controls effects. After each result, Next moves the tested object or pair onto the adjacent table.

Built with HTML, CSS, JavaScript, and locally bundled Three.js. Serve locally with `python -m http.server 8878 --bind 127.0.0.1`, then open `http://127.0.0.1:8878/`. Run collision and full session checks with `node --test tests/*.test.mjs`.

Start development at [For-AI/README.md](For-AI/README.md). This public repository contains browser code, tests, current agent guidance, and the [German terminology and shapes research brief](docs/research/german-blicket-terminology-and-shapes.md). Private correspondence and source archives are excluded. This within-session sequence adapts published AND/OR evidence patterns; it is not a validated research instrument. German comprehension, shape assignments, and phase order still need evaluation for experimental use.
